3. Why Does a Browser Make Several Requests to Show One Page?

A browser makes several HTTP requests because a webpage contains different resources such as HTML, CSS, JavaScript, images, fonts, and other files. Each resource may need to be requested separately from the server before the webpage can be displayed completely.
